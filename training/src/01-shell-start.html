Content checked against the official Claude Code documentation (code.claude.com/docs) on 1 October 2026, Claude Code v2.1.28x. Claude Code ships updates almost weekly — if something on your screen looks different, run /help, check /release-notes, or simply ask Claude "how do I…?".

Learning outcomes

By the end of Day 3 you will be able to…

  1. Explain how Claude Code differs from Claude chat, and pick the right one for a task.
  2. Install, sign in and verify Claude Code on Windows, macOS and in VS Code — and fix the common install errors.
  3. Drive a session confidently: plain-English prompts, @ file mentions, ! shell mode, interrupting and rewinding.
  4. Use the ~25 slash commands that cover almost all day-to-day work.
  5. Choose the right permission mode and write allow / ask / deny rules that keep you safe.
  6. Give Claude lasting project knowledge with CLAUDE.md and manage its context window.
  7. Connect Claude Code to other tools with MCP connectors — and know the security trade-offs.
  8. Turn a repeatable task into your own slash command (a skill) and share it with your team.
  9. Apply the explore → plan → build → verify workflow to real consulting-style work: data, documents, code.
  10. Know where to go next: VS Code, Desktop, web sessions, automation and further learning.
The one-sentence goal

You leave able to hand Claude Code a real, low-risk task from your own work, steer it, check its output, and stay in control of what it is allowed to do.

Orientation

How to use this page

Navigate
  • The sidebar follows the three sessions. Each day starts with a timed agenda and a session clock for the facilitator.
  • Use Search (top bar) to find any command or topic later — this page doubles as your reference manual.
Personalise
  • Pick Windows or macOS in the top bar: install steps, paths and keyboard shortcuts switch to match.
  • Toggle dark mode, and Present for big-screen delivery.
Practise
  • Every grey code box has a Copy button. Boxes marked Type in Claude Code are prompts; the others go in your terminal.
  • Labs, checklists and quizzes save your progress in this browser (nothing is sent anywhere).
Facilitate
  • Turn on Facilitator to reveal timing cues, talking points, live-demo scripts and common pitfalls.
  • Can't install yet? The practice terminal on Day 1 lets you try commands safely in the browser.

Before you share this page: send it to attendees one week ahead with the Before Day 1 checklist highlighted. Ask everyone to complete the install at home if their machine allows it — fixing installs live eats session time. Keep the Facilitator guide open on a second screen.

Accounts & access

Your computer

No admin rights? No problem.

The recommended native installer installs into your user profile and does not need administrator rights on Windows or macOS. If your laptop blocks installs entirely, you can still follow along with the Desktop app, claude.ai/code in the browser, or the in-page practice terminal.
