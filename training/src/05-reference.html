Troubleshooting

Start with claude doctor (shell) or /doctor (in a session). Still stuck? Email your facilitator with a screenshot.

Installation & sign-in

claude isn't found / isn't recognised

Open a new terminal first. Then add the install folder to PATH — Windows: %USERPROFILE%\.local\bin (see the command in Install); macOS: echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc && source ~/.zshrc. If you only installed the VS Code extension, install the CLI too — the extension doesn't add claude to PATH.

Behind a corporate proxy or firewall

Ask IT for the proxy address and set it before installing:

$env:HTTP_PROXY = 'http://proxy.example.com:8080'
$env:HTTPS_PROXY = 'http://proxy.example.com:8080'
irm https://claude.ai/install.ps1 | iex
export HTTP_PROXY=http://proxy.example.com:8080
export HTTPS_PROXY=http://proxy.example.com:8080
curl -fsSL https://claude.ai/install.sh | bash

Test connectivity with curl -sI https://downloads.claude.ai/claude-code-releases/latest (Windows: curl.exe -sI …) — a 200 means you can reach the download server; a 403 usually means a proxy or filter is blocking it. Domains to allow-list: api.anthropic.com, claude.ai, claude.com, platform.claude.com, downloads.claude.ai and (for claude.ai connectors) mcp-proxy.anthropic.com.

TLS errors: unable to get local issuer certificate, SELF_SIGNED_CERT_IN_CHAIN

Your network inspects TLS traffic. Get the corporate CA certificate (a .pem file) from IT. For the install on macOS/Linux: curl --cacert /path/to/corporate-ca.pem -fsSL https://claude.ai/install.sh | bash. On Windows, IT adds the CA to the Windows certificate store. Then point Claude Code at it:

$env:NODE_EXTRA_CA_CERTS = 'C:\path\to\corporate-ca.pem'
export NODE_EXTRA_CA_CERTS=/path/to/corporate-ca.pem
"Claude Code access has not been granted" / 403 after login

Your account doesn't include Claude Code — e.g. the free plan, or a Team/Enterprise seat without a role that includes Claude Code. Ask your admin, or sign in with another account via /login. Run /status to see which account and method are active.

Login fails in WSL, over SSH or in a container

The browser can't reach the local callback. Copy the URL Claude Code prints into a browser on your machine and complete sign-in there; if it asks for a code, paste it back into the terminal.

Windows: "requires either Git for Windows (for bash) or PowerShell"

Neither shell was found. Make sure powershell.exe is on PATH (or install PowerShell 7), or install Git for Windows. If Git is installed but not detected, set CLAUDE_CODE_GIT_BASH_PATH to C:\Program Files\Git\bin\bash.exe in the env block of your settings.json.

Using Claude Code

Too many permission prompts
  • Tick "Yes, and don't ask again" for commands you trust, or add allow rules in /permissions.
  • Run /fewer-permission-prompts to get a suggested allow list from your history.
  • Use Accept-edits mode while iterating, or auto mode for longer tasks you trust.
  • On macOS/Linux/WSL 2, /sandbox lets sandboxed commands run without prompts.
Auto mode keeps blocking something I need

Open /permissions → Recently denied and press r to retry with manual approval, or switch to Manual mode for that step. Name the exact action you approve in your message (e.g. "force-push to my branch feature-x is fine"). Repeated false positives usually mean the classifier lacks context about trusted infrastructure — admins can configure it, and you can report it with /feedback.

Claude ignores my CLAUDE.md
  • Run /context — is the file listed under Memory files? If not, it's in the wrong place.
  • Make instructions concrete ("use 2-space indentation", not "format nicely") and remove contradictions.
  • Trim it — long files dilute important rules. /doctor prompt-audit can review your instruction files.
  • Anything that must always happen belongs in a hook or permission rule.
Claude seems forgetful, slow or confused in a long session

The context is cluttered. Run /context to see why, /compact with a focus, or /clear and restart with a sharper prompt. Put durable instructions in CLAUDE.md, and delegate big investigations to a subagent.

I hit my usage limit

Run /usage to see your limits and what's consuming them. /rate-limit-options shows choices such as waiting for the reset, adding usage credits or upgrading. Long contexts, very high effort and many parallel agents use more.

Something broke after I changed a setting, skill or hook

Start with claude --safe-mode — it disables CLAUDE.md, skills, plugins, hooks and MCP servers so you can tell whether a customisation is the cause. /doctor also flags unparseable settings files and slow hooks.

VS Code: Spark icon missing or Claude never responds

Open a file (the toolbar icon needs one) or use the Status Bar ✻ Claude Code item; check VS Code is 1.94+; run Developer: Reload Window; disable conflicting AI extensions; trust the workspace. If responses never arrive, run claude in a terminal to see a more detailed error.

Facilitator guide

One week before
  • Confirm every attendee has a plan or seat that includes Claude Code.
  • Send this page with the checklist; ask people to install at home if allowed.
  • Test the install on a standard corporate laptop — proxy, TLS inspection, software-install policy.

On the day
  • Projector: switch on Present and Facilitator; start the session clock.
  • Have fallbacks ready: Desktop app, claude.ai/code, the practice terminal.
  • Pair beginners with confident users for labs.
  • Keep a "parking lot" for questions that would derail timing.
Teaching tips
  • Demo live, including mistakes — rewinding a bad edit teaches more than a perfect run.
  • Narrate the transcript: point at each tool call and why Claude made it.
  • Keep labs on synthetic data; never use client data in training.
  • Repeat the core habits daily: plan first, verify, /clear, commit.
After the course
  • Create a team channel; pin this page and one strong example.
  • Run a weekly "what did Claude help you with?" thread.
  • Collect shared skills and CLAUDE.md snippets in a team repo.
  • Offer 15-minute pairing for anyone stuck on their first real task.
